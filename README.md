# 📸 Professional Image Gallery

A modern **Responsive Image Gallery Web Project** built using **HTML, CSS, and JavaScript**.
The gallery includes a **Lightbox view, image navigation, hover effects, and category filters** for a better user experience.

This project demonstrates **front-end web development skills** and responsive UI design.

---

## 🚀 Features

* Responsive Image Gallery Layout
* 20 High-Quality Online Images
* Lightbox Image Preview
* Next / Previous Image Navigation
* Image Hover Effects
* Smooth Transitions
* Category Filters (Nature, City, Animals)
* Fully Responsive Design (Mobile, Tablet, Desktop)

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

1. Download or clone the repository

2. Open the project folder

3. Open **index.html** in your browser
